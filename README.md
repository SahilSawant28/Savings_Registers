# Self Help Group Savings Register

A simple web application to manage the monthly savings of Self Help Group members. Users can add member names, select a month, enter savings amounts, view records, and calculate total savings.

### Technologies Used
- HTML
- JSP
- Java JDBC
- MySQL
- Apache Tomcat

### How to Run
1. Start MySQL and Apache Tomcat.
2. Set up the `savingsdb` database.
3. Update the MySQL password in `result.jsp`.
4. Open `http://localhost:8080/savingsapp/index.html` in your browser.
